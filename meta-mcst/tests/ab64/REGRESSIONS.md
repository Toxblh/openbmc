seen FAIL on the buggy version (red) and PASS on the fixed one (green).

  container). `ST --red` puts each bug back (a mutant of the input) and
  requires the check to FAIL; `ST --root <tree of REV>` runs it on an older
  revision. `RQ` = `test_regressions_qemu.py` (QEMU; groups base, kexec, platform, fruid, hwmon, pns); `REG_RED=1` puts the
  older bugs back on the running BMC, `REG_IMAGE=<old image>` boots the image

  new tests; the integrated run of 20d0979595 (image 1a0ba17e) for the
  existing suites.
