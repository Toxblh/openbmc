# 2026-11-08: BMC не вернулся после установки обновления

Плата: 1Э8СВ-uATX, BMC (REIMU-5564, AST2500), хост Эльбрус.

## Коротко

1. **BMC зависал при каждой перезагрузке Linux** (5 ноября и дважды 8 ноября,
   установка beta6 и beta7). Причина — испорченная маска сброса WDT1
   (`0x1e78501c` = `0x00d76300`): в ней нет процессора ARM (бит 0). Перезагрузка
   Linux — это сброс SoC через WDT1; процессор не сбрасывался, ядро писало
   `Reboot failed -- System halted` и стояло. A/B откатиться не мог: U-Boot
   не запускался, `reimu_tries` оставался 0.
2. **Кто записал маску — неизвестно.** Не наш код, не device tree (ни наш, ни
   стоковый), не драйвер `aspeed_wdt`, не U-Boot (он пишет WDT1C только перед
   своим аварийным сбросом при сбое DRAM или с перемычкой fast reset, её нет),
   не видеодрайвер `ast` хоста. Значение живёт до снятия питания.
3. **С правильной маской перезагрузка BMC жёстко перезапускает хост**
   (сбрасывается графика ASPEED, которую видит хост). С плохой маской хост
   выживал, но BMC умирал. Маска «всё, кроме графики и LPC» (`0x023fdf73`)
   не годится: BMC срывается на обучении DRAM.
4. **Ethernet BMC сломался после моего эксперимента** со сбросом
   `0x023fdf73` (~06:30): передача работает, приёма нет совсем. PHY Micrel
   KSZ8041RNLI защёлкивает режим (стрепы) с приёмных линий RMII
   (RXD1/RXD0/CRS_DV/RX_ER) при своём аппаратном сбросе; производитель прямо
   предупреждает, что MAC может держать эти линии в 1 и PHY защёлкнет не тот
   режим. Регистра для переопределения у KSZ8041 нет (16h зарезервирован).
   Не помогли: полный сброс SoC (3 раза), программный сброс PHY (BMCR бит 15).
   Нужно снять питание платы или дёрнуть `RST#` PHY (pin 32, куда заведён — неизвестно).
5. **Хост терял связь с внешним миром**, потому что маршрут по умолчанию через
   USB-сеть BMC имел метрику 100 (лучше LAN, 101), а Ethernet BMC мёртв.
   Агент на хосте был старый (без `USB_NET_METRIC`, `VERSION` всегда "1.0").
   Обновил агент из beta7 — маршрут через USB стал 700, LAN основной.

## Как спасать зависший BMC с хоста

Утилита `p2a` (мост P2A через BAR1 видеокарты ASPEED, `0000:05:00.0`):
на хосте `~/bmc-rescue/`, в репозитории `meta-mcst/tools/ab64/p2a/`,
копия в `~/git/new-reimu/work/rescue/p2a/`. Нужен root на хосте.

```
# состояние: таймеры WDT1-3 (счётчик дважды через 2 с), SCU
sudo ~/bmc-rescue/p2a diag
# окружение U-Boot из флеша BMC (bootdelay, reimu_slot/tries/pending)
sudo ~/bmc-rescue/p2a dump 0x200e0000 0x20000 /tmp/env.bin
# вся DRAM BMC (журнал старого ядра переживает сброс SoC), ~9 минут
sudo ~/bmc-rescue/p2a dump 0x80000000 0x20000000 /tmp/bmc-dram.bin
# сброс BMC через WDT2 (хост тоже перезапустится). Маску НЕ урезать.
sudo ~/bmc-rescue/p2a wdtreset 5 0x023ffff3
```

Как читать `diag`: все `ctrl` с битом 0 = 0 и счётчики стоят — никто не
загружается (U-Boot в приглашении или процессор стоит). WDT1 `ctrl 0x13`,
`reload 0x03938700` (60 с) и счётчик идёт — работает Linux (systemd).

Журнал старого ядра в дампе: `strings -t x bmc-dram.bin`, искать
`reboot:`, `systemd-shutdown`, `Reboot failed`.

## Доступ к BMC без Ethernet

Через хост по USB-сети: `ssh -J USER@HOST root@172.31.83.1`
(если до хоста нет прямого доступа, добавить промежуточную машину: `-J USER@JUMP,USER@HOST`).

## Что исправлено (локальный коммит dd98f5402d, beta8)

- `aspeed,reset-mask = <0x023ffff3>` у WDT1 в device tree — ядро пишет при каждой загрузке.
- `reimu-logd` раз в 30 с проверяет маску, восстанавливает, пишет критическое событие с найденным значением.
- Хук `systemd-shutdown` (`reimu-wdt-mask`) ставит маску прямо перед перезагрузкой.
- Кнопка «Перезагрузить BMC» предупреждает, что хост перезапустится.
- Тесты: QEMU `regressions.wdt` (красный на beta7, зелёный), static S76 + мутанты. REGRESSIONS 140.

## Что осталось

- На месте: снять питание платы на 10 с (PHY). Сразу после — прочитать маску
  WDT1 (`devmem 0x1e78501c 32`) до установки beta8: если уже `0x00d76300`,
  её пишет что-то при старте.
- Посмотреть, куда идёт `RST#` (pin 32) у KSZ8041RNL — GPIO BMC или общий сброс.
- kexec для плановых перезагрузок (обновление, кнопка, откат A/B), чтобы не ронять хост.
- BMC раздаёт хосту маршрут по умолчанию только при работающем своём Ethernet.
- Версия агента = версия прошивки; предупреждение в UI, если агент на хосте старше.
- Не делать на плате сбросов SoC с урезанной маской.
