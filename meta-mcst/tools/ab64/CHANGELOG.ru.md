# Что нового

Раздел на каждый тег: его показывает страница обновления в веб-интерфейсе BMC.
Простой текст и списки через дефис.

## reimu-2.0-beta4

- KVM: картинка с видеокарты хоста в H.265, если браузер его умеет (иначе H.264). Поток меньше на треть, BMC легче его пересылать. Нужен обновлённый агент хоста: обновите его на странице «Хост».
- Меню источника в KVM короче: адрес хоста только когда агента нет, настройки JPEG только при показе JPEG.
- Служба VNC без клиентов больше не будит процессор BMC 60 раз в секунду (около 4% нагрузки постоянно).
- VNC-порт 5900 закрыт для сети: VNC работает через веб-интерфейс (порт 443); прямой VNC-клиент — через SSH-туннель `ssh -L 5900:localhost:5900 root@<BMC>`, затем клиент на localhost:5900.
- OpenSSL 3.5 вместо 1.1.1 (ветка 1.1.1 больше не получает исправлений) и OpenSSH 9.9 вместо 8.4: закрыта атака Terrapin, появился SFTP. Очень старые SSH-клиенты, которые умеют только ssh-rsa с SHA-1, не подключатся.
- BMC больше не отвечает на поиск имён LLMNR и mDNS в локальной сети.
- Ядро Linux 6.18.60.

## reimu-2.0-beta3

- Страницы открываются и обновляются быстрее: BMC отдаёт всё, что нужно странице, одним ответом, а постоянную часть только когда она изменилась.
- Агент хоста сам ставит и запускает передачу картинки видеокарты в H.264 для KVM. Чтобы это заработало, обновите агент на странице «Хост».
- KVM пишет, почему нет H.264 с хоста: агент не подключён, на хосте нет видеокарты или упала служба захвата.
- Убраны ссылки на старый интерфейс.
- На телефоне поле пароля больше не сбрасывает клавиатуру при входе.
- Карта: разъём X15 проверен кабелем, верхний USB в списке идёт первым.

## reimu-2.0-beta2

- Обновление из интернета: BMC сама проверяет новые версии, показывает, что изменилось, скачивает и устанавливает. Ничего не нужно скачивать на компьютер.
- Файл обновления в релизе теперь называется по версии, например reimu-2.0-beta2.tar.
- Карта платы на странице «Оборудование», три вида на выбор: изометрия, перспектива и сверху. Датчики, вентиляторы и разъёмы, нагрузка BMC, занятые слоты, диски и USB при установленном агенте хоста. Карту можно увеличивать кнопками и перетаскивать.
- Известная проблема: сразу после неудачной записи ПНС новая загрузка образа может получить отказ, пока не завершится прошлая задача. Прочитайте ошибку, подождите несколько секунд и загрузите образ снова: иначе на BMC останется предыдущий файл.

## reimu-2.0-beta

- Первый выпуск: два слота A/B с автоматическим откатом на одной микросхеме 64 МиБ.
- Ядро Linux 6.18, новый веб-интерфейс, управление вентиляторами, защита от перегрева, журнал событий, агент хоста.
